# Shelfstone Frontend

This frontend is built with SvelteKit and Tailwind CSS.

## Open Source Libraries Used

This project utilizes the following open source libraries:

*   **Epub.js**: For rendering EPUB files. ([http://epubjs.org/](http://epubjs.org/))
*   **SvelteKit**: Web application framework. ([https://kit.svelte.dev/](https://kit.svelte.dev/))
*   **Tailwind CSS**: Utility-first CSS framework. ([https://tailwindcss.com/](https://tailwindcss.com/))

More will be added as they are integrated.

Thank you to the creators and maintainers of these fantastic tools!
